# Retail Opportunity Analyzer

An advanced market viability and demographic analysis tool for retail strategists. This application provides real-time insights into market regions, helping users identify lucrative retail opportunities based on population metrics, age demographics, and income levels.

## 🌐 Live Demo

Access the live application here: **[https://retail-analyzer-weld.vercel.app](https://retail-analyzer-weld.vercel.app)**

## 🚀 Features

-   **Interactive Dashboard:** Real-time viability analysis for specific locations.
-   **Light/Dark Theme Toggle:** Seamlessly switch between a professional Light mode (default) and a high-performance Dark mode. All components, including charts, adjust automatically.
-   **Interactive Header Search:** A unified search bar in the header that allows users to instantly change and analyze different locations.
-   **Dynamic News Slider:** A rotating ticker of business and market news, updating every 5 seconds to provide real-time context.
-   **KPI Metrics:** Instant view of Total Addressable Market (TAM), Target Demographics, and overall Viability Score.
-   **Dynamic Charts:** Visual breakdown of Age & Income demographics and 5-Year Growth Projections using Recharts.
-   **AI Market Insights:** Automated strategic recommendations based on current market data.
-   **Strategic Checklist:** Track essential steps like zoning laws and competitor mapping.
-   **Professional PDF Export:** Generate high-quality, centered reports that match your current theme selection (Light or Dark).
-   **Local Storage:** Save and manage multiple market analyses locally.

## 🛠️ Tech Stack

-   **Framework:** [Next.js 15](https://nextjs.org/) (App Router)
-   **Deployment:** [Vercel](https://vercel.com/)
-   **Styling:** [Tailwind CSS](https://tailwindcss.com/) (with Native Dark Mode support)
-   **Icons:** [Lucide React](https://lucide.dev/)
-   **Charts:** [Recharts](https://recharts.org/)
-   **PDF Generation:** [html2canvas](https://html2canvas.hertzen.com/) & [jsPDF](https://rawgit.com/MrRio/jsPDF/master/docs/index.html)
-   **Language:** [TypeScript](https://www.typescriptlang.org/)

## 🚦 Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the results.
